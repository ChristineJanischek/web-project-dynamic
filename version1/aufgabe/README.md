# Aufgabe - Version 1: HTML-Grundgerüst & CSS

## 📋 Deine Aufgabe

In dieser Version lernst du:
- Ein korrektes HTML5-Grundgerüst erstellen
- Semantische Seitenstrukturelemente verwenden
- Eine externe CSS-Datei einbinden
- Grundlegende CSS-Formatierungen anwenden

## 🎯 Was ist vorbereitet?

### HTML (`index.html`)
- ✅ Grundlegendes HTML5-Gerüst mit DOCTYPE
- ✅ Head-Bereich mit Meta-Tags vorbereitet
- ⚠️ **Du musst noch ergänzen:**
  - Aussagekräftigen Titel
  - CSS-Datei verlinken
  - Header mit Logo/Navigation
  - Main-Bereich mit Sections
  - Footer

### CSS (`css/style.css`)
- ✅ Dateistruktur mit Kommentaren vorbereitet
- ⚠️ **Du musst noch implementieren:**
  - Body-Styling (Schrift, Farben, Zentrierung)
  - Header-Formatierung
  - Navigation-Styling mit Hover-Effekt
  - Main-Bereich und Sections
  - Footer-Gestaltung

## 💡 Tipps

- **Arbeite schrittweise:** Erst HTML vervollständigen, dann CSS
- **Teste nach jedem Schritt:** Speichern → F5 im Browser
- **Nutze DevTools:** Rechtsklick → "Untersuchen"
- **Farbideen:** HTML-Farbnamen wie `lightblue`, `coral`, `darkslategray`
- **Vergleiche mit der Musterlösung:** Nur wenn du feststeckst!
