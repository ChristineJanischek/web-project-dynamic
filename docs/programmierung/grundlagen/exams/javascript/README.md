## ⏳ Geplante Themen

- **Datenstrukturen** – Arrays, Sets, Maps, Destructuring
- **Funktionen** – Arrow Functions, Callbacks, Closures, Higher-Order Functions
- **Kontrollstrukturen** – Loops, Switch, Ternär-Operator
- **Dateien** – File API (Browser), Node.js fs module
- **Datenbank** – fetch API, JSON, localStorage, IndexedDB

## 🔑 JavaScript-spezifische Besonderheiten

- **Syntax:** ECMAScript 6+ (const, let, arrow functions)
- **Ein/Ausgabe:**
  - Browser: `prompt()`, `alert()`, `console.log()`
  - Node.js: `readline` module
- **Array-Methoden:** `.forEach()`, `.map()`, `.filter()`, `.reduce()`
- **Fallstricke:** `var` vs `let`/`const`, Hoisting, truthy/falsy values
