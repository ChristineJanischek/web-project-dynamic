## ⏳ Geplante Themen

- **Datenstrukturen** – Arrays, assoziative Arrays, Objects
- **Funktionen** – Anonymous Functions, Closures, Arrow Functions (PHP 7.4+)
- **Kontrollstrukturen** – Loops, Switch, Ternär-Operator
- **Dateien** – `fopen()`, `fread()`, `fwrite()`, `file_get_contents()`, `file_put_contents()`
- **Datenbank** – MySQLi, PDO, prepared statements, transactions

## 🔑 PHP-spezifische Besonderheiten

- **Syntax:** PHP 7.4+ (typed properties, arrow functions)
- **Ein/Ausgabe:**
  - Web: `echo`, POST/GET-Parameter
  - CLI: `readline()`, `fgets(STDIN)`
- **Array-Funktionen:** `array_map()`, `array_filter()`, `array_reduce()`, `foreach`
- **Fallstricke:** `$` bei Variablen, `==` vs `===`, Array-Indizes
