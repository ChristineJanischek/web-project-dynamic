## ⏳ Geplante Themen

- **Datenstrukturen** – Listen, Tuples, Sets, Dictionaries, List Comprehensions
- **Funktionen** – Lambda-Funktionen, Decorators, Generators, \*args/\*\*kwargs
- **Kontrollstrukturen** – Loops, Match-Case (Python 3.10+), Ternär-Operator
- **Dateien** – `open()`, `read()`, `write()`, `with` statement, JSON/CSV
- **Datenbank** – sqlite3, SQLAlchemy, Context Manager

## 🔑 Python-spezifische Besonderheiten

- **Syntax:** Python 3.8+ (walrus operator, f-strings, type hints)
- **Ein/Ausgabe:** `input()`, `print()`
- **List-Funktionen:** `map()`, `filter()`, `reduce()`, List Comprehensions
- **Fallstricke:** Indentation, mutable default arguments, variable scope
