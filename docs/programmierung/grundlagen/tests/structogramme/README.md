# Struktogramme (Basistest)

Ablageort fuer Struktogramme im SVG-Format. Die Dateien werden spaeter mit der Draw.io-Extension erzeugt und hier abgelegt.

## Namenskonvention

- `<Sprache>_Grundlagen_Basistest_Aufgabe_D.svg`

## Vorgesehene Dateien

- `JavaScript_Grundlagen_Basistest_Aufgabe_D.svg`
- `PHP_Grundlagen_Basistest_Aufgabe_D.svg`
- `Python_Grundlagen_Basistest_Aufgabe_D.svg`

## Operatorenstandard

Standard: Operatorenliste fuer Struktogramme des Landes BW.

## Einbindung

Die Loesungsdokumente referenzieren die Dateien direkt aus diesem Ordner.
