# Einfache Ausgaben in Python

[← Zurück zur Python-Übersicht](README.md) · [Weiter: Variablen](VARIABLEN.md)

## Lernziele

- Text und Variablen mit `print()` ausgeben
- Einfache Formatierung mit f-Strings nutzen
- Ausgaben für Fehlersuche und Tests verwenden

## Theorie kompakt

In Python erfolgt die Standardausgabe mit `print()`.

## Deklaration & Implementierung

```python
print("Hallo Welt!")

name = "Mila"
print(f"Hallo {name}!")
```

## Best Practices

- Für Einsteiger konsequent `print()` nutzen
- f-Strings für lesbare Ausgaben verwenden
- Ausgaben klar beschriften

## Häufige Fehler

- Klammern oder Anführungszeichen vergessen
- Variablenname falsch geschrieben
