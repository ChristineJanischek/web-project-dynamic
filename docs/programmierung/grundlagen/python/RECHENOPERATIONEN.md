## Lernziele

- Grundrechenarten anwenden
- Operatoren zielgerichtet einsetzen
- Rechenlogik klar strukturieren

## Theorie kompakt

Wichtige Operatoren:

- `+`, `-`, `*`, `/`, `%`, `//`, `**`

## Deklaration & Implementierung

```python
a = 12
b = 5

print(a + b)  # 17
print(a - b)  # 7
print(a * b)  # 60
print(a / b)  # 2.4
print(a % b)  # 2
```

## Best Practices

- Klammern zur Klarheit verwenden
- Zwischenergebnisse benennen
- Bei Geldwerten Rundung bewusst einsetzen

## Häufige Fehler

- Division durch `0`
- Ganzzahl- und Fließkommawerte verwechseln
