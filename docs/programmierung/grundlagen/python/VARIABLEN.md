## Lernziele

- Variablen korrekt anlegen und nutzen
- Grundlegende Datentypen erkennen
- Gute Variablennamen verwenden

## Theorie kompakt

Eine Variable speichert einen Wert unter einem Namen. Python ist dynamisch typisiert.

Typische Datentypen:

- `str`, `int`, `float`, `bool`, `list`, `dict`

## Deklaration & Implementierung

```python
vorname = "Lea"
alter = 17
note = 1.7
ist_volljaehrig = False

print(f"{vorname} ist {alter} Jahre alt.")
```

## Best Practices

- Sprechende Namen verwenden (`gesamt_preis`)
- Einheitliche Benennung im `snake_case`
- Werte möglichst direkt initialisieren

## Häufige Fehler

- Variablen vor der Zuweisung verwenden
- Groß-/Kleinschreibung verwechseln
