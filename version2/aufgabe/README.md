# Aufgabe - Version 2: Box-Modell & Responsive Layout

## 📋 Deine Aufgabe

In dieser Version lernst du:
- Das CSS Box-Modell verstehen und anwenden
- Responsive Layouts mit Media Queries erstellen
- Ein funktionierendes Hamburger-Menü implementieren
- Flexbox und CSS Grid für flexible Layouts nutzen

## 🎯 Was ist vorbereitet?

### HTML (`index.html`)
- ✅ Grundstruktur mit semantischen HTML5-Elementen
- ✅ Alle Sections vorbereitet (Header, Hero, Box-Demo, Grid, Footer)
- ⚠️ **Du musst noch ergänzen:**
  - Logo-Div im Header
  - Hamburger-Button mit 3 Span-Elementen
  - Navigation mit Links
  - 3 Box-Elemente in der Box-Demo Section
  - 6 Cards im Grid

### CSS (`css/style.css`)
- ✅ Dateistruktur mit Kommentaren vorbereitet
- ✅ Grundlegende Farben (Header, Footer)
- ✅ Font-Familie und Line-Height
- ⚠️ **Du musst noch implementieren:**
  - `box-sizing: border-box` für alle Elemente
  - Container-Zentrierung mit `max-width` und `margin`
  - Flexbox für Header und Navigation
  - Logo als Background-Image
  - Alle 3 Box-Modell Demonstrationen
  - Responsive Grid mit Media Queries
  - Hamburger-Menü Styling und Animationen

### JavaScript (`js/script.js`)
- ⚠️ **Komplett leer - du implementierst:**
  - DOM-Elemente auswählen
  - Event Listener für Hamburger-Button
  - Toggle-Funktionalität für Navigation
  - Menü schließen bei Link-Klick
